# 1945 日本海海上輸送ゲーム

第二次世界大戦末期の日本海を舞台にした海上輸送シミュレーションゲームです。
プレイヤーは新潟―釜山間の輸送を任され、1945年1月から8月まで、毎月の希少資源輸入ノルマの達成を目指します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（単一ファイル、外部ファイル不要）。

毎月、以下の3つを選んで出航します。

- **航路**：最短（高速だが発見されやすい）／標準／遠回り（隠密だが時間がかかり捕捉されやすい）
- **船団規模**：1隻（単独航行）〜8隻。少数精鋭は発見されにくく、大船団は目立つが生き残る割合が高い
- **時間帯**：昼（速いが見つかりやすい）／夜（遅いが見つかりにくい）

## 要素

- B-29が敷設した機雷への触雷、敵潜水艦との遭遇・魚雷攻撃
- 月ごとに上がっていくノルマと、戦争末期に連れて増える損耗率（史料データに基づくバランス調整）
- 備蓄燃料：最短航路は高速航行で燃料消費大、遠回り航路も距離の分だけ消費が増える
- 船員：沈没時、一定割合の乗員を救出できる
- 船の故障：末期に連れて故障率が上昇し、故障した船はその月出港できない（ポップアップで通知）
- BGM：通常時「月月火水木金金」、効果音（出港の汽笛、撃沈時の爆発音ほか）
- 船が0隻になればゲームオーバー、全8か月のノルマを達成すれば完全クリア

## 史料について

船の損耗バランスは、1945年1〜8月の商船損耗・建造実績（[船舶の建造と損耗で見る太平洋戦争](https://w.atwiki.jp/works_petrowka/pages/61.html)）を参考に調整しています。ゲーム内にも「史料ノート」を収録しています。
